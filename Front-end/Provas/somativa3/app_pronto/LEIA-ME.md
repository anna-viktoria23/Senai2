# Lista de Filmes — Somativa Aula 10

## O que este projeto é

Um app de Lista de Filmes que **está QUASE pronto**. Mas tem 2 bugs
escondidos e algumas funcionalidades faltando.

Sua prova é:
1. **Encontrar e corrigir os 2 bugs**
2. **Adicionar 3 funcionalidades que faltam**
3. **Personalizar o visual do site**
4. **Cadastrar 3 filmes reais** que você assistiu

## Como começar

1. Abra o VS Code → Arquivo → Abrir Pasta → escolha esta pasta
2. Clique com botão direito no `index.html` → Open with Live Server
3. **TESTE o app primeiro**: cadastre 1 filme e tente recarregar a página.
   Aperte o botão Excluir. **Anote o que NÃO funciona** — esses são os bugs!
4. Abra a prova (DOCX) e siga os passos

## Dica importante

**Sempre teste depois de CADA mudança.** Salve (`Ctrl+S`) e recarregue
a página (`F5`). Se algo quebrou, é mais fácil descobrir o que foi
alterando uma coisa por vez.

## Console é seu amigo

Aperte **F12** no navegador para abrir o DevTools.
- Aba **Console**: ver erros do JavaScript em vermelho
- Aba **Application** → **Local Storage**: ver os dados salvos

## Se ficar perdido

- Limpe o localStorage: F12 → Console → digite `localStorage.clear()` → Enter
- Recarregue a página com Ctrl+F5
