DHT22

já consegue ligar na porta digital, mas tem que chamara biblioteca DHT

Tem três ligações (de frente) (da esquerda para direita): vcc (ligação positiva), data (ligação digital), nc (not conection, não conecta pois funciona como uma saída de possíveis curtos ou evasão de saída da estática), gnd (conexão negativa).
Conecta o resistor no mesma linha da porta, mas conecta no positivo o outro lado do resistor para dar uma melhor precisão.

slides:
- o que é:
O DHT22 é um sensor que mede a temperatura e a umidade do ambiente de forma digital. Ele é amplamente utilizado em projetos de automação residencial, monitoramento climático e estações meteorológicas.

-o que é preciso para ligar:
* Componentes necessários:
	° 1 Sensor DHT22
	° 1 Resistor 10kΩ (pode ser usado entre o VCC e o pino de dados se necessário)
	° Protoboard
	° Fios jumper
* Portas usadas:
	° Pino de dados conectado a uma GPIO do Raspberry Pi Pico (por exemplo, GP15)
* Bibliotecas necessárias:
	° dht (já integrada em MicroPython no Wokwi)
	° machine
	° utime

- Conexão com o RASPBERRY PI PICO
* VCC do DHT22 -> 3V3 (OUT) do Raspberry Pi Pico
* GND do DHT22 -> GND do Raspberry Pi Pico
* DATA do DHT22 -> GP15 do Raspberry Pi Pico


Explicação dos principais comandos novos:
* DHT22(Pin(15)) cria um objeto sensor ligado ao pino GP15.
* sensor.measure() solicita uma nova medição.
* sensor.temperature() retorna a temperatura em graus Celsius.
* sensor.humidity() retorna a umidade relativa do ar (%).
* O sensor precisa de um intervalo mínimo entre leituras (por isso o sleep(2)).

CÓDIGO: 
from machine import Pin
from utime import sleep
from dht import DHT22

sensor_temp = DHT22(Pin(15))

while True:
    # Diz ao sensor que ele iniciará/solicitará uma LEITURA
    sensor_temp.measure()
    
    # Leitura da UMIDADE
    umidade = sensor_temp.humidity()
    
    
    # Leitura da TEMPERATURA
    temperatura = sensor_temp.temperature()
    
    print("A umidade é: ", umidade)
    print("A temperatura é: ", temperatura)
    
    
    sleep(2)
